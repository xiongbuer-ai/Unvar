# 模型配置与网络

[English](../en/network-setup.md) | 简体中文

## 配置模型服务

在「设置 → 模型服务」点击「新增服务」，选择 OpenAI 兼容接口、Anthropic 或 DeepSeek，填写显示名称、接口地址和模型标识，启用并保存服务。

接口地址与模型标识应以你使用的服务商或自托管服务配置为准。随后输入 API Key 并保存，点击「测试连接」检查配置。连接测试会向所选服务发送一次小型请求，可能消耗服务额度。

API Key 存放在系统凭据存储中，保存后不回显；你可以替换或删除密钥。切换到另一台设备后，需要在该设备重新配置密钥。

在「研究背景」填写研究方向，帮助雷达评估问题与你工作的相关性。

## 哪些操作会发送数据

| 操作 | 发送或获取的内容 |
| --- | --- |
| 保存、编辑和检索记录 | 使用本地工作区，不自动调用模型 |
| 雷达分析 | 读取来源正文，将正文与必要研究背景发送给所选模型 |
| 生成候选结论 | 将所选实验记录发送给模型 |
| 生成提纲、正文或审阅意见 | 将已确认事实包及当前阶段所需写作内容发送给模型 |
| 测试连接 | 向配置的模型服务发送小型测试请求 |

## 网页采集

桌面应用通过系统代理获取静态网页正文，支持 HTML 和纯文本。不会执行网页脚本或转发应用 Cookie，因此需要登录、验证码或客户端脚本渲染的页面可能无法提取正文。此时可以将相关段落手动保存为笔记，再从笔记发起分析。

采集仅支持不含用户名和密码的 HTTP(S) 网址，最多跟随 5 次重定向，正文上限为 2 MB，请求超时为 20 秒。

采集会拒绝显式私网 IP 和明显的本地主机名，但不会在本地解析并校验域名的最终目标 IP，因此无法保证阻止解析到私网的域名。该网络模式依赖可信的系统代理和路由配置。

使用 Clash Verge 等 Fake-IP 代理时，当前桌面采集路径不要求为 Unvar 单独添加域名 DNS 例外。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 无法选择模型服务 | 确认服务已启用，且已保存 API Key |
| 模型连接失败或返回 HTTP 错误 | 检查接口地址、模型标识、密钥、服务额度和网络连接 |
| 来源请求失败或超时 | 检查网址和系统代理是否可访问该页面，再手动重试 |
| 可读正文不足 | 将需要研究的正文摘录为笔记，避免只保存页面标题或导航 |
| 来源格式不支持或超过大小限制 | 改用相关的 HTML 页面，或手动摘录需要的文本 |
| 模型输出校验失败 | 检查来源是否清晰，稍后重试或更换模型；未通过校验的结果不会作为有效结果保存 |
| 无法保存密钥 | 检查当前设备的系统凭据存储权限 |

工作区同步不会迁移密钥，详见[工作区与同步](workspace-folders.md)。

## 通过 OpenRouter 使用 Jev

打开设置 → **Jev / OpenRouter**，在独立字段保存 OpenRouter API Key。保留 `typesafe/jev-1.13`，或填写受支持的明确 Jev 版本，然后测试连接。测试会发起真实 System One 请求，可能产生费用。生成模型服务及其密钥仍独立配置。

勾选启用 Jev 并保存设置后，Radar 新问题会使用 Jev 评分。已有问题提供「使用 Jev 重新评分」和「评分来源与历史」。历史保留实际模型、来源输入、评分、原始答案、用量和耗时。调用失败会明确标记为 **Rules 回退**，不会冒充 Jev 成功。人工覆盖继续生效；取消评分不会启动另一条回退请求。

Pi 选用受限的 `score_question` 工具时，复用同一评分服务。评分仅为建议，不能接受 Finding 或确认 Fact Pack。关闭 Jev 后，普通 Radar 继续使用生成模型评分，Pi 可返回明确标记的 Rules 建议。删除 Jev 密钥会同时关闭 Jev。开发更新涉及主进程或 preload 接口时，请完全退出再启动应用。
