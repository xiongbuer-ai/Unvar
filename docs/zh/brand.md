# 品牌与图标

[English](../en/brand.md) | 简体中文

Unvar 的标识由开口的 U 和右上方独立圆点组成。U 像承接研究材料的容器，圆点代表尚待验证的线索与未命名变量。

## 使用方式

使用炭黑（`#242424`）与白色（`#FFFFFF`），保持原始比例。建议最小显示尺寸为 16 px，四周至少留出标识宽度的 1/8；不拉伸，不添加阴影或渐变。搭配文字时使用名称 **Unvar**，中文名称为 **未命名变量**。
